## Project Overview
An interactive financial dashboard developed using Microsoft Excel to analyze revenue, expenses, profitability, budgets and financial trends.

## Tools Used
- Microsoft Excel
- PivotTables
- Excel Formulas
- Data Visualization

## Key Analysis
- Total Revenue
- Total Expenses
- Gross Profit
- Operating Profit
- Net Profit
- Profit Margin
- Actual vs Budget Revenue
- Actual vs Budget Expenses
- Monthly Revenue Trend
- Revenue Forecast

## Skills Demonstrated
- Data Analysis

- KPI Analysis
